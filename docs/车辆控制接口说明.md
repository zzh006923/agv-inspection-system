# 车辆控制接口说明

## 车辆状态

```http
GET /agv/movement/status
```

用于获取当前车辆运行状态。

## 启动车辆

```http
POST /agv/movement/start
```

将车辆状态切换为运行中。

## 停止车辆

```http
POST /agv/movement/stop
```

将车辆状态切换为已停止。人员靠近、烟雾异常等安全场景会自动调用该能力。

## 重置状态

```http
POST /agv/movement/reset
```

将车辆状态恢复到初始状态。

## 手动设备控制

```http
POST /agv/iot/device/control
Content-Type: application/json
```

```json
{
  "taskId": 1,
  "deviceType": "agv",
  "action": "安全停车",
  "commandText": "执行安全停车",
  "sceneName": "人工控制"
}
```

支持的 `deviceType` 包括 `agv`、`light`、`power` 和 `alarm`。
