# AI助手使用说明

## 1. 文档目的

AI助手是AGV智能巡检手持终端内置的分析工具，基于Dify平台和LLM大模型（Ollama本地部署），为运维人员提供巡检任务的辅助判断、故障分析和处理建议。

AI助手面板集成在任务详情与故障复盘页（/task/:id/detail）右侧。

## 2. 功能说明

AI助手提供六种操作方式：

### 2.1自由问答

在底部输入框输入问题，按Ctrl + Enter或点击发送按钮。AI基于当前任务数据生成回复，支持在同一对话中连续追问。

常用问题示例：

- 现在能上传吗？为什么？
- 这条裂缝应该怎么处理？
- 当前任务还需要做什么？
- 湿度异常和裂缝发现有没有关联？

### 2.2是否可上传

点击是否可上传按钮，AI判断当前任务是否满足上传条件，分析内容包括任务状态、故障总数、待确认故障数、是否存在未复核的异常记录。

### 2.3复核建议

点击复核建议按钮，AI给出哪些故障最需要重点关注、哪些可能为误报、复核的优先级建议。

### 2.4巡检复盘

点击巡检复盘按钮，AI生成完整复盘报告，从总体判断、关键风险、异常关联分析、下一步操作建议、系统处理建议五个维度回答。

### 2.5故障研判

在故障列表中选中一条记录后，点击故障研判按钮可用。AI对选中的故障进行判断，给出该故障是真实异常、疑似异常还是可能误报的结论，以及判断依据、误报可能性和处理建议。同时生成一条可直接复制到系统备注栏的建议备注。

### 2.6生成备注

在故障列表中选中一条记录后，点击生成备注按钮，AI生成一条简短的可复制备注文本，用于填入系统备注栏。

## 3. 数据来源

AI分析时参考以下数据：

- 任务信息：编号、名称、状态、地点、执行人（1条）
- 任务概览：故障总数、待确认数、传感器异常数（1份）
- 当前选中故障：名称、类型、等级、距离、描述（1条）
- 故障列表：名称、类型、距离、确认状态、备注（最多5条）
- 传感器记录：名称、数值、状态、动作（最多5条）
- AIoT联动记录：设备、动作、结果、反馈（最多5条）

当数据量较大时只包含最近的部分记录。

## 4. 典型使用场景

### 上传前检查

进入任务详情页，点击是否可上传按钮查看AI判断。如果存在未确认故障，在故障列表中逐条选中并点击故障研判，根据AI建议确认或标记误报。确认完毕后再次点击是否可上传确认，然后点击页面上方的上传巡检数据。

### 整体任务复盘

任务结束后进入详情页，点击巡检复盘，查看AI的总体判断和关键风险，根据建议逐条确认故障，确认完毕后上传数据。

### 单条故障处理

在故障列表中点击一条记录使其高亮，点击故障研判查看AI判断结果。如果判定为真实异常，点击故障行的复核按钮确认故障并填写备注。也可以点击生成备注，将AI生成的备注复制到系统备注栏，保存复核结果。

## 5. 对话管理

AI助手支持多轮连续对话，同一对话中的上下文会保持连贯。点击快捷按钮会自动发送对应问题，不影响连续对话。刷新页面后会开启新的对话。

## 6. 服务依赖

AI助手正常工作需要以下服务同时运行：

- 后端服务：http://localhost:8088
- Dify平台：http://localhost
- Ollama模型：http://localhost:11434

任一服务不可用时，AI助手会显示对应的错误提示。

## 7. 说明

AI助手的分析基于页面提供的数据摘要和大模型的通用知识，可作为辅助参考提高复核效率，但不能替代人工现场复核和专业判断。AI获取的是最近5到10条记录，如果任务数据量很大，可能无法覆盖全部记录。AI不直接读取故障图片内容，只根据文本描述进行分析。
