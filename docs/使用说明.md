# 使用说明

## 一、系统简介

AGV 智能巡检系统用于模拟或支持智能巡线车巡检任务，系统包含任务管理、缺陷识别、摄像头展示、传感器数据展示、车辆运动控制、AI 智能助手和系统设置等功能。

## 二、运行前准备

运行系统前需要准备：

1. 后端运行环境：JDK、Maven；
2. 前端运行环境：Node.js、npm；
3. 数据库环境：MySQL 或 Kingbase；
4. 可选：YOLO 识别脚本运行所需 Python 环境；
5. 可选：Dify 或本地大模型服务；
6. 可选：真实小车、传感器 Hub 和摄像头设备。

## 三、数据库初始化

根据使用的数据库选择对应脚本。

### MySQL

```text
database/schema.sql
database/data.sql
database/schema_update_real_car.sql
```

### Kingbase

```text
database/schema-kingbase.sql
database/data-kingbase.sql
database/schema_update_real_car.sql
```

初始化完成后，需要在后端配置文件中修改数据库连接信息。

## 四、启动后端

进入后端目录：

```bash
cd backend
mvn spring-boot:run
```

后端启动后，默认提供任务管理、缺陷管理、传感器数据、车辆控制、AI 助手和系统设置等接口。

## 五、启动前端

进入前端目录：

```bash
cd frontend
npm install
npm run dev
```

启动成功后，根据终端输出访问前端页面，例如：

```text
http://localhost:5173
```

## 六、主要功能使用

### 1. 巡检任务管理

用户可以在任务页面进行：

- 查看巡检任务列表；
- 新增巡检任务；
- 修改任务信息；
- 查看任务详情；
- 进入任务执行页面。

### 2. 任务执行

任务执行页面通常包含：

- 当前任务基本信息；
- 小车运动状态；
- 传感器实时数据；
- 摄像头画面；
- 缺陷识别结果；
- 相关操作按钮。

### 3. 摄像头查看

系统可通过摄像头组件展示视频画面。使用前需要确认：

- 后端摄像头接口可访问；
- 摄像头地址配置正确；
- 前端视频播放依赖文件存在；
- 浏览器允许加载相关视频资源。

### 4. 缺陷识别与确认

缺陷识别结果可以通过 YOLO 脚本上传到后端，前端页面可展示识别图片和缺陷信息。

用户可以：

- 查看缺陷列表；
- 查看缺陷图片；
- 确认缺陷；
- 修改缺陷信息；
- 删除错误记录。

### 5. 传感器数据查看

如果已接入传感器 Hub，系统可以展示：

- 温度；
- 湿度；
- 光照；
- 烟雾检测；
- 人体检测；
- 其他实时状态。

### 6. AGV 小车控制

系统提供小车控制接口，可用于：

- 前进；
- 后退；
- 停止；
- 心跳检测；
- 运动状态展示。

实际使用时需要确认后端与真实小车控制地址一致。

### 7. AI 智能助手

AI 智能助手用于提供系统问答或巡检辅助说明。使用前需要确认：

- Dify 服务已经启动；
- 后端 AI 接口配置正确；
- API Key 或接口地址没有写错；
- 前端 AI 面板能够正常请求后端。

### 8. 系统设置

系统设置页面用于查看或修改系统参数。修改后应确认后端配置读取逻辑是否生效。

## 七、YOLO 脚本使用

如果需要运行识别脚本，可以根据实际文件路径运行：

```bash
python frontend/scripts/predict_and_upload_frontend_static.py
```

或：

```bash
python frontend/scripts/realtime_crack_watch.py
```

运行前需要确认：

1. 后端服务已启动；
2. 脚本中的后端接口地址正确；
3. 图片路径正确；
4. YOLO 模型文件存在；
5. 上传接口能够正常返回结果。

## 八、常见问题

### 1. 前端页面打不开

检查：

- 是否执行 `npm install`；
- 是否执行 `npm run dev`；
- 端口是否被占用；
- Node.js 版本是否兼容。

### 2. 后端启动失败

检查：

- JDK 是否配置正确；
- Maven 依赖是否下载成功；
- 数据库是否启动；
- 数据库账号密码是否正确；
- 配置文件是否存在敏感或错误配置。

### 3. 页面没有数据

检查：

- 数据库是否初始化；
- 后端接口是否正常；
- 前端代理地址是否正确；
- 浏览器控制台是否有请求错误。

### 4. 摄像头没有画面

检查：

- 摄像头地址是否正确；
- 视频流是否可播放；
- EasyPlayer 依赖是否存在；
- 后端摄像头接口是否返回设备数据。

### 5. 识别结果没有上传

检查：

- YOLO 脚本是否运行；
- 后端上传接口是否启动；
- 图片路径是否正确；
- 数据库表是否存在；
- 脚本中的任务 ID 或接口参数是否正确。
