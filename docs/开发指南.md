# 开发指南

## 一、开发环境

本项目采用前后端分离结构，开发前需要准备以下环境：

- JDK 8 或以上版本；
- Maven；
- Node.js 与 npm；
- MySQL 或 Kingbase 数据库；
- Git；
- 可选：Python 环境，用于运行 YOLO 识别或上传脚本。

## 二、后端开发

后端代码位于：

```text
backend/
```

常见目录结构如下：

```text
backend/
├─ pom.xml
└─ src/
   ├─ main/
   │  ├─ java/com/example/agv/
   │  │  ├─ common/        通用返回结构
   │  │  ├─ controller/    控制器接口
   │  │  ├─ dto/           请求和响应对象
   │  │  ├─ entity/        数据实体
   │  │  ├─ mapper/        数据访问层
   │  │  └─ service/       业务逻辑层
   │  └─ resources/        配置文件和 SQL 脚本
   └─ test/                后端测试代码
```

### 后端启动

```bash
cd backend
mvn spring-boot:run
```

### 后端测试

```bash
cd backend
mvn clean test
```

### 后端开发规范

1. 新增接口时应放在 `controller/` 下；
2. 业务逻辑应放在 `service/` 下，避免 controller 过重；
3. 数据表实体应放在 `entity/` 下；
4. 数据访问接口应放在 `mapper/` 下；
5. 接口返回建议统一使用通用返回结构；
6. 不要将数据库密码、真实密钥、设备账号写死在开源配置中。

## 三、前端开发

前端代码位于：

```text
frontend/
```

常见目录结构如下：

```text
frontend/
├─ package.json
├─ vite.config.js
├─ public/
└─ src/
   ├─ api/          接口请求封装
   ├─ components/   公共组件
   ├─ router/       页面路由
   ├─ styles/       样式文件
   ├─ utils/        工具函数
   └─ views/        页面视图
```

### 安装依赖

```bash
cd frontend
npm install
```

### 启动前端

```bash
npm run dev
```

### 前端开发规范

1. 页面级组件放在 `src/views/`；
2. 可复用组件放在 `src/components/`；
3. 接口统一写在 `src/api/`；
4. 工具函数统一写在 `src/utils/`；
5. 不要提交 `node_modules/`、`dist/`、`coverage/` 等目录；
6. 如果使用本地环境变量，应提供 `.env.example`，不要提交真实 `.env`。

## 四、数据库开发

数据库脚本建议统一放在：

```text
database/
```

常见文件包括：

```text
schema.sql
schema-kingbase.sql
data.sql
data-kingbase.sql
schema_update_real_car.sql
```

修改数据库结构时应同步更新对应 SQL 文件，并确认 MySQL 和 Kingbase 两种环境下的兼容性。

## 五、模块开发建议

### 1. 任务管理模块

任务管理相关代码通常涉及：

- `AgvTaskController`
- `AgvTaskService`
- `AgvTask`
- `AgvTaskMapper`
- `TaskView.vue`
- `TaskFormDialog.vue`

### 2. 缺陷识别与摄像头模块

缺陷识别相关代码通常涉及：

- `AgvFlawController`
- `AgvAnalysisController`
- `AgvCameraController`
- `FlawDialog.vue`
- `VideoPlayer.vue`
- `image.js`

### 3. 传感器与车辆控制模块

传感器和真实小车接入相关代码通常涉及：

- `AgvSensorController`
- `AgvIotController`
- `AgvMovementController`
- `SensorReportDTO`
- `AgvSensorRecord`
- `AgvMovementStateService`

### 4. AI 智能助手模块

AI 接入相关代码通常涉及：

- `AgvAiController`
- `AgvAiService`
- `DifyService`
- `AiAssistantPanel.vue`

### 5. 系统设置与测试模块

系统配置和测试相关代码通常涉及：

- `AgvConfigController`
- `SystemCheckController`
- `SettingsView.vue`
- `*.test.js`
- `src/test/`

## 六、Git 提交规范

建议使用清晰的提交信息，例如：

```text
feat(task): add inspection task management
feat(sensor): add sensor report API
feat(camera): add camera video preview
feat(ai): add Dify assistant module
test: add frontend component tests
docs: add deployment guide
```

提交前应检查：

```bash
git status
```

确认没有误提交以下目录：

```text
node_modules/
dist/
coverage/
.venv/
target/
logs/
runs/
```

## 七、开源发布前检查

1. 仓库结构是否清晰；
2. 后端、前端、数据库、文档是否分目录存放；
3. `.gitignore` 是否生效；
4. README 是否完整；
5. 是否提供开发指南和使用说明；
6. 是否误提交密钥、密码、日志、依赖和运行产物；
7. 每位成员是否使用自己的账号提交对应模块；
8. commit message 是否能说明修改内容。
