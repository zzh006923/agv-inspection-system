# 缺陷识别与摄像头模块说明

## 一、模块概述

本模块是 AGV 智能巡检系统中的图像识别与缺陷处理模块，主要用于支持巡检过程中的摄像头接入、巡检图像获取、YOLO 缺陷识别、识别结果上传、缺陷信息展示与确认等功能。

该模块将前端视频展示、后端识别结果接收、数据库记录保存和识别脚本联动起来，使系统能够完成从“巡检图像采集”到“缺陷识别与结果展示”的完整流程。

## 二、主要功能

### 1. 摄像头接入

系统提供摄像头设备查询与视频播放相关功能，用于在前端页面中展示巡检摄像头画面，为后续缺陷识别和巡检记录提供图像来源。

主要功能包括：

- 查询摄像头设备信息；
- 前端视频播放组件展示；
- 支持巡检页面中的视频预览；
- 为缺陷识别提供图像数据基础。

相关代码主要包括：

```text
backend/src/main/java/com/example/agv/controller/AgvCameraController.java
frontend/src/components/VideoPlayer.vue
```

### 2. 缺陷识别结果上传

系统支持 YOLO 识别脚本将检测结果上传至后端接口。后端接收识别图片、缺陷类型、置信度、图片路径等信息后，将结果保存到数据库中，供前端页面展示和后续处理。

主要功能包括：

- 接收 YOLO 识别结果；
- 保存识别图片与结果信息；
- 记录上传时间和任务关联信息；
- 支持前端查询和展示识别结果。

相关代码主要包括：

```text
backend/src/main/java/com/example/agv/controller/AgvAnalysisController.java
backend/src/main/java/com/example/agv/entity/AgvUploadRecord.java
backend/src/main/java/com/example/agv/mapper/AgvUploadRecordMapper.java
backend/src/main/java/com/example/agv/service/CloudUploadService.java
```

### 3. 缺陷管理与确认

系统提供缺陷信息管理功能，用于对识别出的缺陷进行展示、确认、修改和处理。前端通过缺陷弹窗展示识别结果，用户可以查看缺陷图片、缺陷类型和相关信息。

主要功能包括：

- 缺陷信息查询；
- 缺陷新增、修改和删除；
- 缺陷确认与状态更新；
- 缺陷图片和识别结果展示。

相关代码主要包括：

```text
backend/src/main/java/com/example/agv/controller/AgvFlawController.java
backend/src/main/java/com/example/agv/entity/AgvFlaw.java
backend/src/main/java/com/example/agv/mapper/AgvFlawMapper.java
frontend/src/components/FlawDialog.vue
```

### 4. 前端图片处理

前端提供图片路径处理与展示工具，用于处理后端返回的图片地址、缺陷图片资源和识别结果图片，保证页面能够正确加载和显示巡检图片。

相关代码主要包括：

```text
frontend/src/utils/image.js
frontend/public/images/
```

### 5. YOLO 识别脚本

系统包含用于识别和上传的辅助脚本，用于将本地或实时识别结果发送到后端接口。

主要脚本包括：

```text
frontend/scripts/predict_and_upload_frontend_static.py
frontend/scripts/realtime_crack_watch.py
frontend/scripts/copy_runs_images_to_frontend.ps1
```

脚本功能说明：

- `predict_and_upload_frontend_static.py`：对静态图片进行识别并上传结果；
- `realtime_crack_watch.py`：监听识别结果并进行实时上传；
- `copy_runs_images_to_frontend.ps1`：将识别输出图片复制到前端可访问目录。

## 四、业务流程

本模块的典型流程如下：

```text
摄像头画面 / 巡检图片
        ↓
YOLO 缺陷识别脚本
        ↓
识别结果上传后端
        ↓
后端保存缺陷和上传记录
        ↓
前端缺陷弹窗展示
        ↓
用户查看和确认缺陷信息
```

该流程能够将巡检过程中的图像数据转化为可管理的缺陷记录，提高巡检系统的信息化和自动化程度。

## 五、运行说明

### 1. 后端运行

进入后端目录后运行：

```bash
mvn spring-boot:run
```

后端默认提供缺陷管理、摄像头查询和识别结果上传相关接口。

### 2. 前端运行

进入前端目录后运行：

```bash
npm install
npm run dev
```

前端启动后，可在对应页面查看视频播放、缺陷展示和识别结果相关功能。

### 3. YOLO 脚本运行

根据实际识别需求运行对应脚本：

```bash
python scripts/predict_and_upload_frontend_static.py
```

或：

```bash
python scripts/realtime_crack_watch.py
```

运行脚本前需要确认后端服务已启动，并根据实际环境修改脚本中的后端接口地址和图片路径。

## 六、注意事项

1. `node_modules/`、`dist/`、`coverage/`、`.venv/` 等目录属于依赖或运行产物，不应提交到开源仓库；
2. `target/`、`logs/` 等后端编译或日志目录不应提交；
3. 如果图片资源较多，建议只保留少量示例图片，避免仓库体积过大；
4. 数据库连接、接口密钥、摄像头账号密码等敏感信息不应直接写入开源配置文件；
5. 实际部署时需要根据本地数据库、后端地址和摄像头地址修改配置。
