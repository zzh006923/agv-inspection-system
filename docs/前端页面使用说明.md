# AGV 智能巡检手持终端前端

本前端按老师《智能巡线车手持终端产品需求》和你们现有 SpringBoot 后端接口生成，使用 Vue 3 + Vite + Element Plus。

## 已覆盖功能

1. 系统自检：文件系统、数据库、车辆通信、摄像头检测，支持演示模式/真实设备模式切换。
2. 任务列表与搜索：按任务编号、创建人、执行人、状态筛选；支持分页。
3. 创建与编辑任务：新增弹窗自动获取任务编号，未执行任务可修改/删除，可创建后立即启动。
4. 实时任务执行：多路摄像头切换、音频开关、车辆前进/停止/后退、实时位置进度、实时故障轮询提醒。
5. 任务详情与故障确认：故障图片查看、路线定位、故障属实/误报复核、备注补充。
6. 数据上传：上传前检查未确认故障，调用后端上传接口，展示上传记录与进度。
7. 系统设置：车辆 IP、端口、控制协议、云端地址、数据库、4 路摄像头账号密码配置。
8. 多传感器创新展示：温度、湿度、光照、烟雾、人员检测，支持场景联动、手动触发、语音/AI 指令、裂缝识别结果写入。
9. 响应式界面：适配 1920×1080 大屏，也能在较小屏幕折叠布局。

## 运行方式

先启动后端，确认后端端口为 `8088`。如果后端端口不是 8088，请修改 `.env.development` 中的 `VITE_API_BASE_URL`。

```bash
cd agv-inspection-frontend
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:5173
```

## 视频播放器接入

老师要求使用 `ZLMRTCClient.js`。当前前端已经在 `VideoPlayer.vue` 中预留了播放器逻辑：

1. 将老师资料/依赖中的 `ZLMRTCClient.js` 复制到：

```text
public/libs/ZLMRTCClient.js
```

2. 打开 `index.html`，取消这一行注释：

```html
<script src="/libs/ZLMRTCClient.js"></script>
```

3. 在系统设置中填写摄像头 RTSP 或 WebRTC/FLV 地址。没有真实视频脚本时，页面会显示视频占位和通道信息，不影响其他功能演示。

## 接真实小车时的建议顺序

1. 后端保持可运行，数据库 `agv_inspection` 已建好。
2. 未连接小车时，系统设置页切换为“演示模式”，先完成页面联调。
3. 连接车载 WiFi 后，在后端 `application.yml` 中将 `agv.mock-mode=false`，并把 `control-mode` 设置为 `http` 或 `tcp`。
4. 前端进入“系统设置”填写车辆 IP、端口、摄像头地址。
5. 回到“系统自检”重新检测。
6. 先测试心跳和停止，再测试前进/后退。



## 裂缝图片显示说明

本版本已针对裂缝识别脚本做了图片显示兼容：

- 后端数据库保存 `/images/crack/xxx_predict.jpg` 时，前端优先访问 `public/images/crack/xxx_predict.jpg`。
- 如果实际文件只有 `xxx.jpg`，前端会自动尝试同名无 `_predict` 文件。
- 如果演示数据保存 `/images/flaw/xxx.jpg`，前端也会自动尝试 `public/images/flaw` 与 `public/images/crack` 两个目录。

推荐目录：

```text
agv-inspection-frontend-runs-ready
└── public
    └── images
        ├── crack   # Python 裂缝识别预测图
        └── flaw    # 老师演示故障图或其他故障图
```

如果你后续重新运行 Python 识别脚本，建议使用：

```text
scripts/predict_and_upload_frontend_static.py
```

它会把预测后的图片自动复制到 `public/images/crack`，不需要手动改数据库路径。
