# 前端页面使用说明

## 1. 文档目的

本文档面向 AGV 智能巡检系统的前端使用者，说明任务列表、任务表单、实时任务执行和任务详情复盘页面的使用方式。

任务模块前端主要包含：

```text
任务列表页
新增/修改任务对话框
实时任务执行页
任务详情与故障复盘页
```

---

## 2. 页面入口与路由

| 页面 | 路由 | 主要用途 |
|---|---|---|
| 任务列表 | `/tasks` | 查询、新增、修改、删除和启动任务 |
| 实时任务执行 | `/task/:id/execute` | 视频监控、车辆控制和实时数据查看 |
| 任务详情 | `/task/:id/detail` | 故障复核、上传检查和数据归档 |

项目使用 Hash 路由时，浏览器地址通常类似：

```text
http://localhost:5173/#/tasks
```

前端调用后端的默认地址通常为：

```text
http://localhost:8088
```

---

## 3. 任务列表页

页面标题：

```text
任务列表与巡检管理
```

### 3.1 顶部功能

顶部按钮包括：

| 按钮 | 作用 |
|---|---|
| 系统自检 | 进入系统自检页面 |
| 系统设置 | 进入系统配置页面 |
| 新增任务 | 打开新增巡检任务对话框 |

### 3.2 状态统计卡片

页面展示：

```text
全部任务
待巡视
巡视中
待上传 / 已完成
```

其中：

- “全部任务”使用后端返回的总记录数；
- 其余状态数量根据当前页任务数据计算；
- 因此状态分类数只代表当前页，不一定代表数据库全部任务。

### 3.3 查询条件

支持以下查询条件：

| 条件 | 查询方式 |
|---|---|
| 任务编号 | 模糊查询 |
| 创建人 | 模糊查询 |
| 执行人 | 模糊查询 |
| 状态 | 精确查询 |

状态选项：

```text
待巡视
巡视中
待上传
已完成
```

操作方法：

1. 输入查询条件；
2. 点击“搜索”；
3. 点击“重置”可清空条件并返回第一页。

### 3.4 任务列表字段

任务表格展示：

```text
任务编号
任务名称
起始地点
距离
创建人
执行人
状态
创建时间
操作
```

点击任务编号可以进入对应页面：

- “巡视中”任务进入实时执行页；
- 其他状态进入详情页。

### 3.5 不同状态的操作按钮

| 任务状态 | 页面显示的主要操作 |
|---|---|
| 待巡视 | 启动、修改、删除、详情 |
| 巡视中 | 继续巡视、详情 |
| 待上传 | 复盘上传、详情 |
| 已完成 | 查看记录、详情 |

后端会再次校验状态，因此通过修改前端页面强行显示按钮也不能绕过业务限制。

### 3.6 分页

页面支持：

```text
每页 10 条
每页 20 条
每页 50 条
```

切换页码或每页数量后，页面会重新加载任务列表。

---

## 4. 新增任务

点击“新增任务”后打开对话框：

```text
新增巡检任务
```

### 4.1 表单字段

| 字段 | 是否必填 | 示例 |
|---|---|---|
| 任务名称 | 是 | 1号线 K12+300-K12+800 区间巡检 |
| 任务编号 | 是 | TASK202607100001 |
| 起始地点 | 是 | A端风井入口 |
| 巡检距离 | 是 | 500m |
| 创建人 | 是 | 运维管理员 |
| 执行人 | 是 | 巡线车操作员 |
| 备注 | 否 | 路线说明、注意事项或巡检重点 |

### 4.2 任务编号

新增对话框打开后会自动请求下一个任务编号。

用户也可以点击编号输入框后的“生成”按钮重新获取。

编号可以手动调整，但应避免与已有任务重复。

### 4.3 创建后立即启动

新增模式下可以勾选：

```text
立即启动并进入实时巡视页
```

保存成功后：

- 未勾选：返回任务列表，任务状态为“待巡视”；
- 已勾选：自动调用启动接口并进入实时执行页。

### 4.4 保存与校验

点击“保存任务”后，前端先执行必填校验。

保存失败时页面显示后端返回的错误信息。

---

## 5. 修改任务

只有“待巡视”任务显示“修改”按钮。

修改页面会回显现有任务信息。修改完成后点击“保存任务”。

注意：

- 已经启动的任务不能修改；
- 后端会再次检查任务状态；
- 任务 ID 必须存在；
- 已逻辑删除的任务不能修改。

---

## 6. 删除任务

只有“待巡视”任务显示“删除”按钮。

删除步骤：

1. 点击“删除”；
2. 确认任务编号；
3. 点击确认；
4. 删除成功后刷新列表。

该操作为逻辑删除，数据库中的历史记录不会直接物理清除。

---

## 7. 启动任务

只有“待巡视”任务显示“启动”按钮。

启动步骤：

1. 点击“启动”；
2. 后端将状态改为“巡视中”；
3. 写入任务执行时间；
4. 页面跳转到实时任务执行页。

如果任务状态已经变化，后端会拒绝启动，并显示错误信息。

---

## 8. 实时任务执行页

页面标题：

```text
实时任务执行
```

页面用于巡检过程中的实时监控和操作。

### 8.1 顶部按钮

| 按钮 | 作用 |
|---|---|
| 返回任务列表 | 返回任务列表页 |
| 完成巡检 | 正常结束任务并进入复盘页 |
| 终止巡检 | 终止任务并进入复盘页 |

完成和终止前都会弹出确认框。

### 8.2 多路视频监控

页面支持最多四路摄像头：

```text
前方视角
左侧视角
右侧视角
后方视角
```

可执行：

- 切换摄像头；
- 开启或关闭音频；
- 刷新监控组件。

如果视频不能播放，检查：

```text
VITE_WEBRTC_BASE_URL
摄像头 ID
转流服务是否启动
FLV 地址是否可访问
```

浏览器不能直接播放 RTSP，项目会将摄像头 ID 转换为：

```text
/live/{cameraId}_01.flv
```

### 8.3 巡检进度

进度条展示：

- 当前车辆位置；
- 任务总距离；
- AGV 位置标记；
- 故障位置标记；
- 故障确认状态。

点击故障标记可以打开故障信息对话框。

巡检距离建议输入可解析的数字和单位，例如：

```text
500m
```

### 8.4 车辆状态与控制

车辆状态区展示：

```text
系统时间
运行状态
行驶方向
故障数量
连接模式
```

控制按钮：

```text
前进
停止
后退
```

真实设备环境下，应先确认周围安全，并优先测试停止功能。

### 8.5 传感器演示

页面提供以下演示按钮：

| 按钮 | 模拟内容 |
|---|---|
| 温度正常 | 正常温度记录 |
| 湿度异常 | 湿度异常记录 |
| 光照不足 | 光照异常记录 |
| 烟雾报警 | 烟雾异常及联动 |
| 人员靠近 | 人员检测及安全联动 |
| 裂缝识别 | 写入裂缝分析结果 |

触发后页面会刷新故障、传感器和联动记录。

### 8.6 场景联动

支持：

```text
安全保护模式
环境监测模式
补光巡检模式
烟雾报警模式
```

操作完成后，设备动作和反馈会显示在“联动”标签中。

### 8.7 语音或 AI 指令

输入框支持示例：

```text
查询当前环境状态
打开补光灯
执行安全停车
```

按 Enter 或点击“发送”后提交指令。

### 8.8 实时记录

页面右侧包含三个标签：

```text
故障
传感器
联动
```

数据每 3 秒自动刷新，也可以点击“刷新”手动刷新。

新故障第一次出现时会弹出通知，之后不会反复弹出同一记录。

### 8.9 完成巡检

点击“完成巡检”后：

1. 页面提示确认；
2. 尝试发送停车指令；
3. 调用任务结束接口；
4. 任务状态变为“待上传”；
5. 页面跳转到任务详情页。

### 8.10 终止巡检

点击“终止巡检”后：

1. 页面提示终止确认；
2. 尝试停止车辆；
3. 结束当前任务；
4. 任务状态变为“待上传”；
5. 备注记录“任务被终止”；
6. 已产生的数据保留用于后续复盘。

## 9. 任务详情与故障复盘页

页面标题：

```text
任务详情与故障复盘
```

### 9.1 顶部按钮

| 状态 | 按钮 |
|---|---|
| 巡视中 | 继续巡视 |
| 待上传 | 上传巡检数据 |
| 全部状态 | 返回任务列表 |

### 9.2 状态统计

页面展示：

```text
故障总数
未确认数量
传感器记录数量
上传状态
```

### 9.3 巡检路线与故障定位

页面根据任务距离显示故障位置。

点击故障位置标记后，可以查看：

```text
故障图片
故障名称
故障描述
故障等级
故障距离
故障来源
确认状态
```

如果一个图片地址加载失败，页面会尝试其他候选字段或地址。

### 9.4 故障历史列表

列表字段：

```text
名称
类型
等级
距离
来源
确认状态
备注
操作
```

操作：

- “查看”：滚动并展示故障详情；
- “复核”：打开故障复核对话框；
- 已复核记录显示“修改”。

### 9.5 故障复核

复核时可以：

```text
确认故障
标记误报
修改等级
填写备注
```

保存后页面重新加载故障列表和上传检查。

系统将备注中包含“误报”的记录显示为误报状态。

### 9.6 任务基本信息

页面展示：

```text
任务名称
起始地点
创建人
执行人
开始时间
结束时间
任务状态
```

### 9.7 上传前检查

点击“检查”后，页面重新读取：

```text
任务状态
故障总数
未确认故障数
上传记录
是否允许上传
```

若存在未确认故障，页面提示继续复核。

### 9.8 传感器与联动闭环

“传感器”标签：

- 每种传感器只展示最新一条记录；
- 显示名称、数值、状态、时间和位置。

“设备动作”标签：

- 最多展示最近的动作记录；
- 显示设备、场景、动作、结果和反馈。

### 9.9 AI 辅助复盘

详情页集成 AI 辅助面板，可结合：

```text
任务信息
故障记录
传感器记录
设备动作
上传汇总
当前选中的故障
```

生成辅助分析。AI 结果用于辅助判断，不应替代人工复核。

### 9.10 上传巡检数据

上传步骤：

1. 点击“上传巡检数据”；
2. 页面重新刷新故障和上传检查；
3. 确认所有故障已经复核；
4. 在确认框中确认上传；
5. 等待上传完成；
6. 任务状态变为“已完成”；
7. 页面刷新故障和上传记录。

上传内容包括：

```text
任务信息
故障记录
传感器记录
AIoT 联动记录
已有上传记录
```

## 10. 常见提示与处理

### 10.1 “只有待巡视任务可以启动”

当前任务已经启动或状态已被其他页面修改。刷新任务列表后再操作。

### 10.2 “只有待巡视任务可以修改”

任务已经进入执行或归档流程，不能再修改基础信息。

### 10.3 “只有待巡视任务可以删除”

已启动任务已经可能产生故障或传感器数据，因此不允许删除。

### 10.4 “只有巡视中的任务可以结束”

任务当前不是“巡视中”。先刷新页面确认状态。

### 10.5 “存在未确认故障/异常”

进入详情页逐条复核故障，确认属实或标记误报后再次上传。

### 10.6 视频无法播放

依次检查：

```text
摄像头服务是否可访问
webrtc-api 是否启动
VITE_WEBRTC_BASE_URL 是否正确
摄像头 ID 是否匹配
生成的 FLV 地址是否可访问
```

### 10.7 车辆按钮无响应

检查：

```text
后端服务
车辆网络
控制模式
车辆地址
心跳接口
后端日志
```

没有真实设备时可使用 Mock 模式。

### 10.8 列表状态统计不等于总数量

分类状态数来自当前分页数据。切换页码后数字可能变化，这是当前实现方式。

### 10.9 无故障任务无法点击上传

当前前端本地条件要求故障总数大于 0，而后端允许“待上传且未确认数为 0”的任务上传。后续应统一使用服务端返回的：

```text
summary.canUpload
```

作为最终按钮条件。

## 11. 前端环境配置

常用配置示例：

```env
VITE_API_BASE_URL=http://localhost:8088
VITE_WEBRTC_BASE_URL=http://设备地址/webrtc-api
VITE_CAMERA_STREAM_1=cam1
VITE_CAMERA_STREAM_2=cam2
VITE_CAMERA_STREAM_3=cam3
VITE_CAMERA_STREAM_4=cam4
```

启动前端：

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

不要将真实设备密码、摄像头认证信息或其他敏感信息写入公开仓库。
