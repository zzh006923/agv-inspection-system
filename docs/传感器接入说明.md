# 传感器接入说明

## 上报地址

传感器数据通过后端接口上报：

```http
POST /agv/sensor/report
Content-Type: application/json
```

如果不传 `taskId`，后端会自动绑定当前最新的巡检中任务。

## 数据格式

温湿度一体传感器：

```json
{
  "sensorType": "th",
  "temperature": 28.6,
  "humidity": 63.2,
  "distance": 12.5
}
```

单一传感器：

```json
{
  "taskId": 1,
  "sensorType": "temperature",
  "temperature": 36.2,
  "distance": 18.0
}
```

支持的 `sensorType` 包括：

- `th`: 温湿度一体上报
- `temperature`: 温度
- `humidity`: 湿度
- `person`: 人员检测
- `light`: 光照
- `smoke`: 烟雾

## 异常阈值

- 温度大于等于 `35` 触发异常
- 湿度大于等于 `80` 触发异常
- 光照低于 `50` 触发异常
- 人员检测为 `true` 触发异常
- 烟雾检测为 `true` 或烟雾数值大于等于 `50` 触发异常
