# 真实小车接入说明

## 硬件代码位置

真实小车侧传感器示例代码位于：

```text
hardware-sensor/sle_demo_th_backend.c
```

该示例用于采集温湿度数据并向后端传感器接口上报。

## 后端接口

真实小车上报数据使用：

```http
POST /agv/sensor/report
```

车辆运动状态由后端服务维护，控制接口集中在：

```http
GET  /agv/movement/status
POST /agv/movement/start
POST /agv/movement/stop
POST /agv/movement/reset
```

## 接入流程

1. 前端启动巡检任务。
2. 小车侧程序采集传感器数据。
3. 小车侧程序向 `/agv/sensor/report` 上报数据。
4. 后端根据阈值生成传感器记录、缺陷记录和 IoT 联动记录。
5. 前端任务执行页和任务详情页展示实时传感器状态。
